# 과제 의도 및 콘텐츠 재검토

검토일: 2026-10-15. 명세서 3~5·6~20·22쪽을 코드 내용과 대조했습니다.

## 과제의 실제 범위

이번 03회차의 목표는 HTML·CSS·Bootstrap 5.3으로 도서 서비스의 반응형 화면을 구성하는 것입니다. 서비스 전체 설명에 AI 분석·창작 지원이 나오지만, 이번 회차의 필수 기능은 Navbar·Hero·Carousel·Grid·Flexbox·Card·통합 HTML·로그아웃 확인 Modal입니다. 실제 AI API, 로그인 서버, 검색 엔진, 게시글 데이터 저장까지 구현하라는 요구는 없습니다.

명세는 지정된 필수 기능을 유지하되 그 외 콘텐츠와 스타일은 자유롭게 작성할 수 있다고 설명합니다. 따라서 예시 스크린샷과 모든 문장이 같아야 정답인 과제가 아닙니다. 다만 제목·작가 등 사실 정보와 필수 도서 상세 연결은 정확해야 합니다.

## 재검토에서 발견하여 수정한 점

1. **작품과 작가의 수상 이력 혼동:** 채식주의자를 노벨 문학상 수상작으로 표현했던 문구를 수정했습니다. 작품은 2016년 인터내셔널 부커상 수상작이고, 한강은 2024년 노벨 문학상 수상 작가입니다. 확인되지 않은 실시간 Top 10 순위 표현도 제거했습니다.
2. **마이 페이지 연결:** 추천 영역으로 이동하던 연결을 준비 중 안내 Modal로 바꿨습니다. 이번 회차에 실제 마이 페이지 구현은 요구되지 않지만 메뉴 이름과 다른 영역으로 이동하는 것은 적절하지 않았습니다.
3. **F309의 절반 겹침:** 기존 구현의 실제 겹침은 102px / 332.3125px, 약 30.7%였습니다. 상단 section 여백 때문에 반이 아니었습니다. 패널 높이 계산에 맞춰 상단 여백과 음수 margin을 조정했습니다. 최종 수치는 `content-browser-checks.json`에 기록합니다.
4. **장르 항목 크기:** 넓은 화면에서도 타일이 과도하게 넓어지던 것을 제한했습니다. 기본 높이 200px, 타일 최대 폭 200px, 기본 4열을 유지합니다. 576px 이상이면서 공간이 좁은 화면에서는 80% 섹션 폭과 4열 조건을 함께 충족하도록 폭을 줄입니다. 명세에 장르 타일의 구체적인 픽셀 폭은 지정돼 있지 않습니다.
5. **제출 문서와 예시 데이터:** 구현 과정과 기술 회고를 보강하고, 쓰레드와 AI 추천이 화면 예시임을 명시했습니다. 완료된 코드에 남아 있던 작성 지시 주석을 정리했습니다.

## 판정과 제한

제공 명세의 이번 회차 목적에 맞는 반응형 화면 프로젝트입니다. 필수 기능은 구현돼 있으며, 개인 취향에 따른 문구 변경이나 실제 AI 서버 추가가 정답의 필수 조건은 아닙니다.

선택 과제 F311의 외부 지도는 HTTP 200 응답을 확인했지만 검사 브라우저의 iframe에서 빈 화면으로 표시됐습니다. 직접 지도 열기 링크를 제공하며, 실제 도서 대여 여부는 확인하지 않았습니다. 이 외부 지도 표시까지 포함해 완벽하게 검증됐다고 단정하지 않습니다. 팀원의 실제 개인 감상이나 기여도를 확인한 것은 아니므로 문서에 그러한 경험을 임의로 기록하지 않았습니다.

명세서 22쪽에는 각자의 계정에 프로젝트를 생성하라는 제출 조건도 있습니다. 현재 확인한 개인 저장소는 정용철의 `jyc686397/03-pjt`입니다. 김정훈을 이 저장소의 팀원으로 등록한 것과 김정훈 본인 계정의 별도 제출 저장소가 존재하는지는 서로 다른 사항입니다. 팀원 본인 계정의 저장소 유무는 확인하지 않았습니다.
