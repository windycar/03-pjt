## 최초 판정과 수정

최신 ZIP은 핵심 요구사항이 상당 부분 구현된 제출 후보입니다. 그대로 완성본으로 확정하기에는 배포 진입점·README·화면 캡처가 없고 반응형 장르 배치가 보완되어야 했습니다.

1. 저장소 루트에 실제 메인 화면인 `index.html`을 추가하고 `06-main.html`과 동일한 구현을 유지했습니다.
2. 필수 F305 장르 목록을 너비 계산 기반 Flexbox 4열로 수정했습니다. 기존 200px 고정 타일은 576px 이상에서 2~3열로 줄어들 수 있었습니다.
3. 통합 메인은 필수 Flexbox 장르 목록을 사용합니다. 심화 CSS Grid는 `04-genre_list_grid.html`에 별도로 보존했습니다.
4. 베스트셀러의 제목/도서 영역 분리와 Hero 겹침 시작점을 992px에 맞추고, 320px 화면에서는 고정 150px 표지가 한 열로 배치되게 보완했습니다.
5. 모바일 메뉴 배경, 메인·상세·섹션 연결, 접근성 레이블을 보완했습니다.
6. 실행 방법·구현 범위·검사 내역·기술 학습 기록을 README에 추가했습니다.
