## 실행

`index.html`을 브라우저에서 열거나, 이 폴더에서 `python -m http.server 8033` 실행 후 `http://localhost:8033`으로 접속합니다. Bootstrap과 지도는 외부 연결이 필요합니다. 별도의 API 키나 빌드 과정은 없습니다.

## 검사와 수정

최신 ZIP의 구현 파일을 이전 스켈레톤 ZIP 및 프로젝트 03 명세서와 비교했습니다. 배포 진입점·README를 추가했고, 좁은 화면에서 장르가 4열을 유지하지 못하는 문제를 수정했습니다. 통합 화면은 필수 Flexbox 장르 목록을 사용하고 심화 Grid를 별도 파일로 보존했습니다. 320px 화면의 표지 넘침, 중간 화면의 베스트셀러 배치, 모바일 메뉴 가독성, 메인·상세 연결도 보완했습니다.

실제 검증 결과와 화면 캡처는 `docs/검사결과.md` 및 `docs/screenshots/`에서 확인할 수 있습니다.
문구·도서 표지·독립 파일과 통합 화면의 내용 일치 여부를 재검사한 결과는 `docs/내용검토.md`에 있습니다.

## 구현 과정에서 확인한 점

- 고정 200px 장르 타일은 화면이 좁아지면 자동으로 2~3열이 됩니다. 필수 4열을 유지하려면 타일 너비를 부모 너비와 간격에서 계산해야 합니다.
- Bootstrap의 breakpoint와 사용자 정의 CSS breakpoint를 함께 맞춰야 표지·제목이 겹치지 않습니다.
- 독립 HTML에서 정상인 경로도 통합·배포 후 다시 확인해야 합니다. 상대 경로를 사용하면 GitHub Pages의 `/03-pjt/` 하위 경로에서도 동작합니다.
- 필수 Flexbox 구현과 심화 CSS Grid 구현을 각각 보존하면 두 요구사항을 별도로 확인할 수 있습니다.
- Bootstrap JS는 Carousel·Collapse·Modal·Tab 동작에 필요합니다.

## 구현 과정과 회고

먼저 명세서의 필수 F301~F308과 선택 F309~F311을 분리하고, 01~05 독립 파일의 도서·장르·쓰레드 내용이 통합 파일에도 그대로 들어갔는지 대조했습니다. 그다음 576px 메뉴·열 수 전환과 이미지 경로, Carousel·Modal·Tab의 동작을 확인했습니다.

어려웠던 부분은 고정 크기와 반응형 열 수, Hero와 베스트셀러 패널의 겹침을 동시에 맞추는 일이었습니다. 장르 목록은 높이를 200px로 유지하고 넓은 화면의 타일 폭을 최대 200px로 제한했습니다. 좁은 일반 화면에서는 4열을 유지하도록 폭을 균등하게 줄이고, 576px 미만에서는 100% 폭의 단일 열로 전환합니다. 베스트셀러는 음수 여백만 임의로 설정하면 패널의 절반이 겹치지 않으므로, 표지·제목·패널 여백으로 높이를 계산해 겹침량을 맞췄습니다.

이번 구현에서 확인한 점은 페이지가 열리는지, 명세의 화면을 충족하는지, 설명 문구가 사실에 맞는지를 각각 확인해야 한다는 것입니다. HTTP 200만으로는 잘못된 메뉴 연결이나 작가와 작품의 수상 이력 혼동을 찾을 수 없습니다. 화면 구성 단계에서는 Bootstrap 컴포넌트와 반응형 배치에 집중하고, 실제 AI 계산·회원 인증·게시글 저장은 별도 기능이라는 범위도 명확히 기록하는 것이 중요합니다. 이 부분은 실제 구현과 검사 결과를 정리한 기술 회고입니다.

## AI 보조 및 콘텐츠 출처

Codex를 요구사항 대조, 코드 보완, 화면 검사, 문서 정리에 사용했습니다. 베스트셀러 목록은 제공 자료로 구성한 예시이며 실시간 판매 순위가 아닙니다. AI 추천 영역은 과제용 화면이며 실제 추천 모델을 호출하지 않습니다. 쓰레드의 인물·본문·좋아요 수는 화면 검증용 예시 데이터입니다.

도서 표지 12개는 제공 이미지의 제목을 육안으로 대조했습니다. 『채식주의자』의 2016년 인터내셔널 부커상 수상과 작가 한강의 2024년 노벨 문학상 수상은 [The Booker Prizes의 도서 정보](https://thebookerprizes.com/the-booker-library/books/the-vegetarian) 및 [작가 정보](https://thebookerprizes.com/the-booker-library/authors/han-kang)를 기준으로 구분했습니다.

## 구현 범위와 제출 전 확인

이번 과제는 화면 구성 단계입니다. 로그인·실제 로그아웃·개인화 AI·실시간 검색·실제 대여 조회·쓰레드 작성/저장·페이지별 데이터 조회는 백엔드와 연결되지 않은 화면 예시입니다. Navbar의 마이 페이지는 준비 중 안내를 표시하며, 다른 메뉴의 콘텐츠로 잘못 이동하지 않습니다. 도서 검색 메뉴는 현재 장르별 목록으로 이동합니다. 지도는 국회도서관 위치 예시이며 실제 소장·대여 여부를 보장하지 않습니다.

원본 강의 PDF와 강의 예제의 API 관련 파일은 공개 배포에 포함하지 않았습니다. 사용자 제공 이미지·폰트는 과제 화면 표시 목적으로 사용했습니다. 담당 강사 Maintainer와 팀원 Developer 등록을 완료했습니다. 팀원별 느낀 점은 문서 마지막에 정리했습니다. 외부 지도 응답은 HTTP 200을 확인했지만 검사 브라우저의 iframe에서는 빈 화면으로 보여, 상세 페이지에 Google 지도 직접 열기 링크를 추가했습니다.
